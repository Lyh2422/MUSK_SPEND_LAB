# MUSK SPEND LAB

一个以公开财富快照为基准的马斯克财富消费模拟小游戏。

玩家可以购买手机、名表、跑车、私人飞机、游艇、豪宅，以及学校、未来城市和火星计划等大型项目，直观感受数千亿美元财富的量级。

## 主要功能

- 24 种不同价格区间的消费项目
- 1 倍、10 倍和 100 倍批量购买
- 自定义任意消费金额
- 实时剩余资产进度条
- 消费账单、撤销和重置
- 1%、10% 和 50% 财富里程碑
- 桌面端与移动端自适应

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录启动一个静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 在线发布

项目包含 GitHub Pages 自动发布工作流。仓库需要在 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**；之后每次推送到 `main` 分支都会自动更新网页。

## 数据说明

游戏采用 2026 年 10 月公开财富榜单快照作为起始值。净资产会随市场变化，商品价格亦为量级估算，本项目仅供娱乐和财富尺度展示。
